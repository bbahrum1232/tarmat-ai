# Tarmat.ai Worker

Planned responsibilities:
1. Download/receive an authorized source file.
2. Extract audio.
3. Transcribe with timestamps.
4. Detect candidate clip ranges.
5. Render 9:16 video with FFmpeg.
6. Burn or package subtitles.
7. Store rendered MP4.
8. Report job progress to the web app.

Do not implement a downloader that bypasses platform restrictions.
